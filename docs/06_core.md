## 根拠の弱いところ

- 「向きは生成AIが持つ」は、AI が少数の事例から傾きを読める根拠が弱い。少数の事例からの規則の抽出は苦手で、確信度も較正されていない（確認：要旨）。著者は合意したが、根拠としては見立てのまま
- 「言語が範囲を持つ」の根拠は、AI が前の選択と矛盾しやすいという観測（確認：要旨と一部本文）。範囲を検査する言語側の仕組みは、まだ何も確かめていない
